<h1 align="center">Bach</h1>

<p align="center">
  <strong>One <code>bach.toml</code> in, one <code>Setup.exe</code> out.</strong><br>
  Modern, clean Windows installers with a native window, in-place updates<br>
  and a clean uninstaller. No installer script, no administrator prompt.
</p>

<p align="center">
  <a href="https://usebach.app">Website</a> ·
  <a href="https://usebach.app/docs/quickstart">Quickstart</a> ·
  <a href="https://usebach.app/docs">Docs</a> ·
  <a href="https://github.com/usebach/bach/releases">Releases</a>
</p>

```bash
npm install --global @usebach/cli
bach init && bach build
```
