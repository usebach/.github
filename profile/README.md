## Products

- **[Bach Installer](https://github.com/usebach/bach-installer)**: modern, clean Windows installers from one `bach.toml`. One `Setup.exe` with a native window, in-place updates and a clean uninstaller. MIT licensed.

```bash
npm install --global @usebach/cli
bach init && bach build
```

## Repositories

- **[usebach/bach-installer](https://github.com/usebach/bach-installer)**: the `bach` command, the installer window and the docs.
